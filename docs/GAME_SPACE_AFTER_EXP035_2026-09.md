# Game-space competition after EXP-035 — September 2026

## Starting point
EXP-035 survives its predeclared ablations: editable structure and autonomous flow are qualitatively coupled. This is not yet evidence of a game. The higher-order question is whether a minimal extension can make the situation generate contextual decisions, learning and surprise rather than a single obvious correction.

The visual-world signal is preserved separately. It is presentation capital, not gameplay evidence.

## Selection rule
A candidate deserves EXP-036 only if:
1. its extra property changes the decision structure, not merely difficulty or spectacle;
2. removing it gives a qualitatively weaker decision space;
3. the probe needs at most one new conceptual property beyond an already acquired coupling, or is an equally cheap unrelated coupling;
4. no score, progression, economy, narrative or content sequence is needed to make the question meaningful;
5. a first-time human can reveal the discriminant through behavior or spontaneous language.

## A — Editable structure × autonomous flow × conflicting local interests
External evidence: Into the Breach's designers explicitly connect varied goals/priorities to interesting choices: saving buildings, mechs and objectives can demand different sacrifices. Its telegraphed attacks make consequences knowable before commitment. Mini Metro similarly makes a player-authored structure answer to multiple simultaneous demands rather than one fixed path.

Genesis inference: EXP-035 already supplies readable causal agency. Adding a second autonomous interest is valuable only if one local edit can help one trajectory while harming or excluding another. That would turn `make the mote reach the target` into `which consequence do I shape for now?`.

Counterexample/risk: two targets can collapse into an obvious ordering puzzle, or into arbitrary sacrifice if their values are not intrinsically legible. Adding health, points or unequal rewards would contaminate the test.

Clean ablations:
- one autonomous interest: should reduce toward EXP-035's dominant correction;
- two interests that are aligned: more activity but little conflict;
- two interests with a shared consequential edit: required novelty is a real choice where the same edit cannot satisfy both immediate futures.

Cost: low-medium. Can reuse deterministic local flow and one gesture. No economy required.

Human discriminant: before or immediately after an edit, player treats one local consequence as a sacrifice/tradeoff relative to another, or changes strategy when the same geometry presents a different conflict.

Game-space potential: high if situations can be generated by geometry rather than authored content.

## B — One action × two mechanically useful consequences
External evidence: Downwell's gunboots became the defining mechanic because firing attacks and recoil changes movement; Fumoto described the multiple purposes as the source of potential. SUPERHOT likewise changes ordinary movement because movement also advances time.

Genesis inference: this remains the strongest unrelated runner-up from the previous competition. It could yield contextual action value with extremely small input vocabulary.

Counterexample/risk: if both consequences are always desirable together, there is no decision—only efficiency. A derivative recoil/time-copy would test familiarity.

Ablations:
- consequence A only;
- consequence B only;
- coupled, with situations where their desired directions diverge.

Cost: medium because the hard part is inventing a non-derivative, immediately readable pair.

Human discriminant: player withholds, redirects or times the same action because one consequence is useful while the other is currently costly.

Game-space potential: high, but current concrete instantiation quality is weaker than A.

## C — Information revealed by action × local commitment
External evidence: Desktop Dungeons makes exploration simultaneously reveal space and spend a recoverable strategic resource because exploration heals both player and wounded monsters. The important structure is not fog-of-war itself but that acquiring information changes the state you are trying to reason about.

Genesis inference: could create learning and contextual commitment without speed or dexterity.

Counterexample/risk: hidden information easily becomes guessing. Desktop Dungeons needs substantial combat arithmetic before the tradeoff is meaningful; Genesis must not import that stack.

Ablations:
- reveal without consequence;
- commitment with full information;
- coupled reveal that changes a local future.

Cost: medium-high because a clean, self-explanatory state is not yet identified.

Human discriminant: player deliberately delays revealing/committing because they infer that information acquisition itself changes options.

Game-space potential: promising, but poor immediate probe.

## D — Autonomous process × reciprocal world transformation
External family: systemic games often become richer when the process does not merely read player-authored structure but also changes it, forcing later actions to respond to consequences of earlier ones. This is a general feedback-loop pattern rather than evidence for one specific game.

Genesis inference: in EXP-035 the mote reads terrain but leaves no trace. If flow also altered terrain, each successful routing could prepare or damage the next situation, potentially making consequence become future context.

Counterexample/risk: reciprocal change can become uncontrolled cascade/spectacle, a failure mode already seen in Genesis. If the player cannot predict the trace, it is noise; if the trace is always beneficial, it is just animation/progression.

Ablations:
- flow reads structure but does not alter it (EXP-035 baseline);
- process alters structure without player editing;
- reciprocal coupling where player edit affects flow and flow predictably affects later editable state.

Cost: low-medium.

Human discriminant: player makes an edit partly for the state it will leave after the process passes, not only for immediate arrival.

Game-space potential: potentially generative, but risks recreating cascade fascination without decisions.

## Comparison
A has the strongest immediate information value because it asks the exact question EXP-035 leaves open: can causal control create a nontrivial decision when consequences conflict? It also has a clean negative result: if the player simply solves one path then the other, or if one edit dominates, the extension fails without requiring interpretation.

B remains the strongest unrelated family and should stay alive; it may ultimately be a better core verb. C is conceptually deep but expensive to make legible. D is cheap and generative-looking but has a known Genesis failure mode around spectacle/cascade.

## Selection
**SELECT A for EXP-036, but only in its strict form: one shared editable structure, two autonomous local interests, and at least one edit whose immediate consequences genuinely conflict.**

Do not add scores, unequal rewards, enemies, lives, progression or authored level sequence. The probe must answer whether the world itself can pose a choice.

Predeclared kill test: if the player can satisfy both interests sequentially with no sacrifice, or one local edit is obviously dominant in every state, DROP this instantiation. Positive evidence requires a spontaneous tradeoff, strategy change, or anticipation of mutually incompatible immediate consequences.

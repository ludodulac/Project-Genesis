## Règle de routage

Si un test humain échoue, identifier d'abord la couche : règle fondamentale, prédictibilité, représentation visuelle ou interface. Ne pas charger une idée parquée ni ajouter une explication visuelle pour masquer une règle qui n'est pas humainement prédictible.

Après conclusion d'une primitive importante, consulter aussi le radar et décider explicitement entre approfondir, combiner ou rouvrir l'exploration externe. Une expérience promue n'est jamais automatiquement « le jeu Genesis ».

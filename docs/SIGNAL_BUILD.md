# SIGNAL

SIGNAL is the selected Genesis game direction. This is a product game, not an EXP.

The representative build is a short real-time routing game: a small visible network carries three kinds of flow toward matching destinations. The player physically moves or rotates a maximum of four visible local routing operators while packets already in flight preserve the consequences of earlier decisions. Congestion must be recoverable before it becomes terminal. A run ends in a real win or loss and restarts into a structurally different seeded situation.

Product question: does real-time manipulation of local rules create anticipation, recovery, learning, and spontaneous replay with a different plan?

No meta progression, campaign, lore, leaderboard, hidden automation, operator configuration menus, or content volume may be used to compensate for a weak core.

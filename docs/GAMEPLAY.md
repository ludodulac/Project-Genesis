# Gameplay retenu

Ce document ne contient que les mécaniques suffisamment éprouvées pour devenir des règles du jeu.

## État actuel

Aucune mécanique n'est encore promue comme gameplay définitif.

Le geste « toucher une cellule pour modifier le relief » est actuellement une hypothèse testée dans `LAB.md`, pas encore une règle sacrée du jeu.

## Critères de promotion d'une expérience

Une mécanique peut entrer ici lorsqu'elle est :
- compréhensible dans le contexte du jeu ;
- plaisante ou stratégiquement intéressante lors de tests réels ;
- compatible avec les principes du projet ;
- suffisamment générale pour être implémentée dans le moteur sans dépendre d'un prototype particulier.

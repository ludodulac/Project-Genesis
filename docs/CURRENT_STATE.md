# Current State

## État réel
Genesis ne cherche pas encore à terminer un jeu. Il cherche le jeu qui donnera une bonne raison d'être terminé.

Deux catégories restent distinctes :
- **primitives acquises** : interactions qui ont démontré quelque chose d'utile et restent disponibles ;
- **candidats de jeu** : expériences jetables qui doivent produire une vraie raison d'agir avant d'être prolongées.

## Primitive acquise — relief tactile

Le grand monde en cases et relief n'a pas été supprimé. Il reste disponible comme langage tactile possible, sans obligation de le mettre dans le prochain jeu.

## Pari humain actif — pression spatiale globale
**Statut : probe technique validé, test humain à faire.**

Question discriminante : **un geste global et simple peut-il créer une intention parce qu'il résout le présent tout en fabriquant simultanément le problème futur ?**

Le probe utilise :
- un plateau 4×4 ;
- un seul geste : swipe dans une direction ;
- le geste déplace l'ensemble du plateau d'une case ;
- une règle de contact minimale ;
- une entrée suivante visible et entièrement déterministe ;
- saturation puis reset court ;
- aucun score, niveau, upgrade, tutoriel stratégique ou hasard caché.

Ce qui doit tuer rapidement le pari : si le joueur ne commence pas spontanément à préserver de l'espace, anticiper l'entrée ou attribuer un échec à une décision spatiale antérieure, ne pas enrichir le prototype.

## Toujours absent par défaut
Score, niveaux, progression, économie, backend, comptes, multijoueur et contenu destiné à sauver une mécanique faible. Ces éléments pourront revenir uniquement si une hypothèse ultérieure les exige pour être testée, pas comme pansement.
